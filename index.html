Enter your TMDB API key

This app loads data directly from The Movie Database. You need a free key. Get one at themoviedb.org/settings/api. It is stored only in your browser (localStorage) and never sent anywhere except TMDB.

OMDb key — Academy Award data

TMDB has no Oscar data, so Academy Award wins & nominations come from OMDb. This key also fills in an age rating or box-office figure for films TMDB has none for (OMDb's box office is US domestic gross, not worldwide — labeled "(US)" with a dashed border when used). Get a free key at omdbapi.com/apikey.aspx (the free tier allows 1,000 lookups/day). Stored only in your browser.

Note: Oscar wins are exact. Oscar nominations are exact only for films that didn't win; for winners OMDb doesn't expose the count, so the number shown is a floor (= wins), except for record-holders which are hand-corrected.

Cloud sync (Firebase)

Paste your Firebase project's web config to sync each profile's "seen" list across devices. Get it from the Firebase Console → Project settings → General → Your apps → Add app (Web) → SDK setup and configuration. You can paste the whole const firebaseConfig = {...} snippet as-is.

Requires Anonymous sign-in enabled (Build → Authentication → Sign-in method) and a Firestore database with a rule allowing signed-in access, e.g. allow read, write: if request.auth != null; on /profiles/{id}. Stored only in this browser — not sent anywhere except your own Firebase project.
